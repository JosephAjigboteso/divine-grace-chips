# Divine Grace Chips — upgraded static website

Pages:
- `index.html` — redesigned home page, brand story, image carousel, features, video and contact CTA.
- `products.html` — full product catalogue using the product images and prices from the Google Site.
- `order.html` — product selector, quantity controls and Web3Forms order submission.

## Web3Forms
Replace `YOUR_WEB3FORMS_ACCESS_KEY` in `order.html` with your Web3Forms access key before accepting orders.

## Notes
The product photos are referenced from the publicly hosted Google Sites image URLs so the actual Divine Grace product photography is retained. The website does not use generated product illustrations.


Revamp: refined light/dark palette and rebuilt the brand collage with native scroll-progress animation for smoother desktop and mobile scrolling.
